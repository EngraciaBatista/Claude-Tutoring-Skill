# Explaining at High level

For Build High and Explore tour High. "Match the user" in [teaching-style.md](teaching-style.md) still decides how much background to give.

- Write for someone learning to code: explain what the code does and the language feature behind each part.
- Go through it line by line or block by block: what each line does, why it's needed, and what happens without it.
- Show real values: what a variable holds, and a table tracing a run when something changes over time.
- No stories, characters, or child-like comparisons. Use an analogy only if the user asks or gets stuck.
